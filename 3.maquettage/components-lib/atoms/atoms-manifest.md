# Manifeste : Atoms

Ce fichier répertorie tous les atomes de Notepad disponibles dans `components-lib/atoms/`.

- [Logo](logo/index.html) : Logo principal Indigo-600.
- [Nav-Link](nav-link/index.html) : Lien de navigation Slate-600/900.
- [Btn-Primary](btn-primary/index.html) : Bouton d'action principal Indigo-600.
- [Badge-Category](badge-category/index.html) : Badge de catégorie Indigo-100.
- [Form-Input](form-input/index.html) : Champ texte avec label Slate-700.
- [Form-Textarea](form-textarea/index.html) : Zone de texte multiligne avec label.
- [Form-Select](form-select/index.html) : Liste déroulante avec label.
- [Form-Checkbox](form-checkbox/index.html) : Case à cocher avec label.
- [Btn-Icon-Action](btn-icon-action/index.html) : Boutons d'édition et suppression (icones).
- [Badge-Visibility](badge-visibility/index.html) : Badges Public/Privé.
- [Title-H1](title-h1/index.html) : Titre principal stylisé.
- [Flash-Message](flash-message/index.html) : Alertes de succès ou d'erreur.
