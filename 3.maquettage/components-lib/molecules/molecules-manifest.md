# Manifeste : Molecules

Ce fichier répertorie toutes les molécules de Notepad disponibles dans `components-lib/molecules/`.

- [Navbar-Public](navbar-public/index.html) : En-tête avec logo et accès auth.
- [Navbar-Private](navbar-private/index.html) : En-tête dashboard avec profil utilisateur.
- [Hero-Section](hero-section/index.html) : Section d'appel à l'action principale.
- [Filter-Bar](filter-bar/index.html) : Barre de recherche et filtres par catégorie.
- [Note-Card-Public](note-card-public/index.html) : Carte pour la grille de notes publiques.
- [Dashboard-Header](dashboard-header/index.html) : Titre H1 + Bouton "Ajouter une note".
- [Note-Table-Row](note-table-row/index.html) : Ligne de tableau pour la gestion des notes privées.
- [Footer-Simple](footer-simple/index.html) : Pied de page standard.
- [Modal-Confirm](modal-confirm/index.html) : Fenêtre de confirmation de suppression.
- [Modal-Editor](modal-editor/index.html) : Formulaire d'ajout/édition en modale.
